## Task 1: Hangman Game

**Description:** The Hangman Game is a text-based word-guessing game developed using Python. The computer randomly selects a word from a predefined list, and the player must guess the word one letter at a time.

**Features:**
- Randomly selects a word from a list of predefined words.
- Allows the player to guess one letter at a time.
- Displays correctly guessed letters and underscores for hidden letters.
- Limits incorrect guesses to 6 attempts.
- Displays a winning message or the correct word when the game ends.

**Concepts Used:**
- Python functions
- `random` module
- `while` and `for` loops
- `if-else` statements
- Lists and strings
- User input and output
- Conditional logic

**How to Run:**
- Make sure Python is installed on your computer.
- Open the project folder in VS Code.
- Run the following command in the terminal:

```bash
python Hangman.py
```

**Technologies Used:**
- Programming Language: Python
- Code Editor: Visual Studio Code
- Version Control: Git and GitHub

**Objective:** The objective of this project is to strengthen Python fundamentals, improve logical thinking, and understand how loops, conditions, and random selection can be used to develop a simple interactive game.
